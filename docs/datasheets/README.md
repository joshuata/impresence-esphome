# Datasheets

The design follows these third-party datasheets, drawings and 3D models. They belong to their manufacturers and are **not committed**: every subfolder here is git-ignored. Download each file from the URL below into the listed path, then check its SHA-256 to confirm you have the same revision the design was based on.
